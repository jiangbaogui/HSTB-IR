# HSTB-IR

Historical Spatiotemporal Baseline Implicit Representation for surface reflectance modeling and prediction from satellite time series.

The [Enga landslide example](examples/enga_landslide/README.md) provides the inference code, a fitted deployment model, the historical calibration profile, a processed Sentinel-2 target image, and interpreted reference samples. Follow the example instructions to reproduce the date-specific reflectance baseline and downstream disturbance screening.
